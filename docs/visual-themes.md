# 页面主题

导航栏的 🌿 按钮开启「温馨森林」，🌸 按钮切回原始主题。日夜模式独立切换。选择保存在浏览器 `visual-theme` 中；第一次访问仍使用原始主题，存储不可用时当前页仍可切换。

## 结构与扩展

- `src/styles/forest.css`：以 `html[data-visual-theme='forest']` 限定配色和页面样式，避免改动原始主题。新增主题时使用新的属性值，并在初始化、按钮切换和样式中注册。
- `src/components/ForestWorld.astro`：共享的雪花、原创 SVG 小宠物及鼠标粒子。宠物呼吸、眨眼和跳跃使用 CSS 动画，点击后更新问候语。
- `public/themes/forest.svg`：原创森林插画，无远程图片或字体依赖。后续可以替换背景或加入独立的动画素材。
- `src/layouts/BaseLayout.astro`：在首次绘制前恢复选择，挂载主题组件。

使用系统「减少动态效果」时关闭飘雪和鼠标粒子，并停用宠物动画。装饰元素不会拦截页面点击；主题和宠物按钮支持键盘操作。粒子节流且自动删除，不使用永久逐帧动画循环。

宠物是网页内动画组件，动画使用 SVG + CSS，便于缩放和扩展。没有引入 GIF 文件或 ChatGPT Work 宠物。
