# 页面主题

导航栏 🌊 开启「海蓝诗境」（Poetize 风格），🌸 切回原有樱花主题。太阳 / 月亮只切换浅色和深色，两个选择互相独立。

`visual-theme` 保存 `original` 或 `poetize`；第一次访问使用樱花，旧 `forest` 自动迁移到 `poetize`。存储禁用时按钮仍可切换当前页。审查链接可带 `?visual-theme=poetize`，应用后移除此参数，避免刷新覆盖之后手动选择。

## 第二版视觉与交互

- 首页使用原创精细海岸绘画、较短首屏、半透明打字字幕、两层起伏的波浪和可点击下行入口；正文使用作者侧栏与双列配图卡片。触屏改为单列，保留原内容和路由。
- 文章使用另一幅原创面海书桌绘画作为标题背景；文章自身封面保留在正文摘要旁，可点击放大，Escape 关闭并返回焦点。
- 海边动效（见下文「海边动效」）、导航下划线、图片渐进放大、阅读进度、返回顶部和专注阅读按钮。动画按钮记住开关；系统减少动态效果时停用，页面隐藏或非当前主题时停止动画循环。工作台和文档不启用装饰动画。
- 樱花原布局保留。视觉样式以 `html[data-visual-theme='poetize']` 限定；不改变文章 Markdown、已有鉴权或发布流程。

- `src/components/PoetizeEffects.astro`：海边动效画布、动画偏好、阅读工具及封面灯箱。
- `src/lib/coastal-sea.ts`：海鸥、波光与气泡的渲染，以及每幅插画的天空 / 海面区域表。
- `public/themes/poetize-{coast,writing}.webp` 和对应 `-mobile.webp`：本次原创生成的绘画，见 [资源来源](theme-assets.md)。没有下载参考站独有插画。
- `src/layouts/BaseLayout.astro`：首次绘制前恢复偏好；挂载主题组件。

## 即时 Markdown 编辑

工作台 `/notes/` 新增默认「即时」模式。标题、段落、列表、引用、代码、链接、图片和表格按块原位排版；点击块编辑它的 Markdown，空行、离开块或 Ctrl/⌘+Enter 后恢复排版。完整 Markdown textarea 仍是唯一正文源，不进行 HTML 反向序列化。

保留源码、分栏和阅读模式，以及原保存、导出、鉴权和显式发布流程。即时与源码共用撤销历史；输入法组合期间保留活动编辑控件。没有新增依赖或外部 CDN。

这是块级即时编辑，并非完整复刻 Typora：活动块仍显示 Markdown 标记，表格通过源码编辑；即时模式使用顶部插入菜单，斜杠菜单保留在源码模式。复杂跨块扩展（如脚注、图表）以源码/阅读模式为准。

### 无账号体验入口

`/editor-preview/?visual-theme=poetize` 是可直接访问的独立演示页，复用同一个 `LiveMarkdown` 类。它只使用示例文档与 `codeverse.editor-preview.draft.v1` 浏览器草稿，提供即时/源码、撤销/重做和 Markdown 导出。它不导入工作台、GitHub 同步或发布模块，不读取令牌，也不访问文档 API。外部图片与 PlantUML URL 在插入 DOM 前替换为占位说明，避免把输入内容发送到外部渲染服务；原 Markdown 保留供导出。正式 `/notes/` 的鉴权没有改变。

### 动效细节补充

保留已确认的插画与排版，追加一次性的侧栏／列表卡片轻入场、仅精细指针启用的卡片悬浮、键盘焦点描边与配图反馈、目录当前项轻移、阅读进度柔和跟随、灯箱入场和主题配色过渡。主题切换不替换 DOM，编辑器光标与 Markdown 保持不变。触屏不依赖悬浮；减少动态效果时跳过入场和切换过渡。隐藏页面停止装饰动画，离开页面释放新增观察器及动画帧。

### 海蓝字体层级

仅 Poetize 使用统一的系统无衬线栈（系统 UI、苹方、冬青黑体、微软雅黑、Noto Sans CJK 与 sans-serif 回退），不下载字体、不依赖字体 CDN。首屏／页面标题 500，导航 500，卡片／正文小标题 600，正文 400、16px／1.9 行高；代码与源码编辑使用本地等宽字体栈。樱花主题原有字体规则保留。

### 海边动效

海蓝诗境不再使用粉色花瓣，改为海边元素，仍共用一个 `#coastal-sea` 画布和右下角的海浪按钮（「关闭 / 开启海浪与海鸥动画」）：

- 海鸥：桌面同时最多 3 只、手机 2 只，在头图插画的天空里横向滑翔，滑翔与扇翅交替，进出天空边缘时淡入淡出。航线压在固定导航栏下沿以下；矮头图把天空裁掉时，改为贴着最大一片海面的上半部掠过。靠近标题、按钮等文字时淡去，像从文字背后穿过
- 波光：只在插画的海面上闪烁，以横向碎光为主、约四分之一是四角星，寿命 0.7–1.6 秒；按可见海面面积控制频率（桌面最多 9 次/秒、同时 16 个，手机 4 次/秒、8 个），避开文字，也不落在头图底部的浪花遮罩上。深色模式略调暗
- 气泡：仅在原本允许花瓣的页面（首页、读书、项目、生活、标签、友链、关于等），桌面 9 个、手机 5 个，从视口底部缓缓升起、左右轻摆，升到约三到六成高度前淡出。博客筛选页与文章页不出现气泡
- 波浪：两层浪花遮罩加快为 42 秒 / 28 秒一轮，并各自上下起伏；遮罩条宽 300%、单块正好一屏宽，每轮平移一整块，循环无跳变
- 头图插画以 46 秒为周期极缓慢地推近、平移（最多放大 4.5%）
- 指针：鼠标移动留下上浮的小气泡，点击（表单控件、对话框除外）泛起两圈水波，同屏最多 3 个，约 0.9 秒后移除

区域表 `SCENE_ZONES` 用插画原图的 0–1 坐标描述天空与海面，运行时按 `object-fit: cover` 与计算后的 `object-position` 换算到屏幕，所以头图裁切、首页竖画和缓慢推近时都能对齐。区域每秒重新测量一次，逐帧只减去滚动量；头图离开视口且页面没有气泡时停帧并隐藏画布，滚回头图再恢复。所有绘制都裁剪在导航栏下方。

桌面最多 60fps、手机 30fps，DPR 上限 1.5 / 1.25；波光与气泡使用预绘制图块，海鸥是两段二次曲线。暂停偏好沿用 `poetize-effects`；减少动态效果、专注阅读、页面隐藏、工作台 / 文档 / 编辑演示和打印时全部停止（指针气泡、水波隐藏，波浪与插画动画暂停）。回归测试：`npm run test:coastal`。

### 潮汐转场

站内链接切页时，海蓝诗境用「潮汐两式」代替樱花转场，画在独立的 `#coastal-tide` 画布上（层级在导航栏之上，不接收指针）：

- 浪扫（切换栏目）：一道半透明浪花从旁边涌入。往导航右侧的栏目走，浪从左边来；往左走则从右边来；从文章回列表算作往回，从右边来；无法判断时随机。浪头是白色泡沫线，后面拖着约六成屏宽、逐渐透明的海水和两道淡浪纹
- 涨潮（进入文章 `/blog/<slug>`，系列页除外）：海水从底部漫上来，新页上再涨一点，然后退到底部以下

旧页沿用导航的 340ms 停留：浪头先到屏幕中间（浪扫约 52%，涨潮约六成高）；响应慢时只缓缓再推进一点，不会在旧页上走完。新页续接同一道浪（形状、方向与相位不变），浪扫约 1.1 秒移出另一侧，涨潮约 1.15 秒退下；整段一般 1.2–1.5 秒，海水始终半透明。

交接沿用樱花的做法：`SakuraNavigation` 在海蓝诗境下派发 `coastal-navigation-*` 事件，渲染器把浪的类型、方向、种子、浪头位置和相位写入 `coastal-navigation-tide-v1`（sessionStorage，10 秒过期，只在 URL 匹配的目标页消费一次）。新页的脚本执行前，头部内联脚本先按记录给 `html` 设上 `data-coastal-arrival`，由 CSS 画出同一位置的静态水面，画布第一帧接手后移除；若脚本没能运行，静态水面 1.6 秒后自行淡出，所以首屏不会先露出新页再被水盖住。

Escape、关闭海浪动画、切换主题或页面隐藏会取消停留，浪原路退回；网络放弃后同样退回。历史前进 / 后退恢复的页面直接显示为无水状态。动画关闭、减少动态效果、专注阅读、工作台 / 文档或存储不可用时，链接立即走原生导航。回归测试同属 `npm run test:coastal`，导航层测试在 `npm run test:sakura`。

### 樱花花风与页面入场

樱花主题现在共用分层落樱画布，支持「风起」、独立暂停、减少动态效果偏好和短暂花风入场。手机正文停帧，文章与目录避让，快速导航和历史恢复沿用原生多页行为。实现、性能上限和回归方式见 [樱花动效](sakura-motion.md)。
