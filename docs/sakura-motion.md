# 原版樱花主题的轻柔动效

首页沿用 `e3cc136` 的居中布局、粉紫渐变、标题、打字文案、星形装饰和按钮。`src/pages/index.astro` 与 `BaseLayout.astro` 恢复为该版本；移除后来增加的树插画、宋体排版和首页重排。本次只细调共享樱花动效与页面淡入。

## 与原版动效的差别

| 项目 | 原版 e3cc136 | 当前 |
| --- | --- | --- |
| 花瓣池上限 | 桌面 60，手机 24 | 桌面 10，手机 4，省流量 3 |
| 花瓣尺寸 | 8–27px，翻转时压缩至 28% | 桌面 26–36px，手机 22–30px，至少保留 78% 厚度 |
| 常态落速 | 15–38px/s，加较大摆动 | 9–18px/s，加不超过 3px/s 轻摆 |
| 风起 | 突然加速并重排部分花瓣 | 9 秒正弦平方曲线渐起渐止，位置连续，不增发花瓣 |
| 入场与恢复 | 自动触发一阵风 | 花瓣分批缓慢淡入，不自动触发风起 |
| 页面转场 | 横扫花瓣遮罩、标题位移 | 850ms 轻淡入（不透明度 0.88 → 1），无横扫、遮罩和位移 |

花瓣保留有缺口的单瓣轮廓、粉色渐变及细边缘。渲染集中在两侧留白，首页文字区不增加低透明度粒子层，也不绘制风线。鼠标只施加经过平滑的微小风力；快速重复点击不会堆积粒子、重置花瓣位置或延长当前风。

## 阅读、无障碍与性能

- 独立暂停沿用 `sakura-effects` 偏好；减少动态效果时不绘制樱花与页面淡入。暂停后首页标题和按钮始终可见。存储被禁用时仍可控制当前页。
- 保留 `e3cc136` 的阅读保护：窄桌面文章隐藏控件时同时停帧、清空 Canvas、取消入场；宽桌面只在安全边缘绘制，并保留可操作的暂停控件。手机离开首屏或进入正文停止绘制。
- 页面隐藏、离开页面时停帧并取消当前风。BFCache 返回恢复偏好和滚动位置，只有一个动画循环，不自动触发新风。
- 桌面绘制最多 30fps，手机／省流量最多 24fps；DPR 桌面最多 1.5、手机最多 1.25，总后备像素不超过约 300 万。共享固定花瓣池与预绘制图块，没有新依赖或外部素材。
- 海滨主题、记录工作台、编辑器、项目文档不启用樱花动效。原生多页导航、链接、锚点、前进后退与滚动恢复不被接管。

## 验证

```sh
npm run test:sakura
npm run test:toc
npm run test:covers
npm run check
npm run build
npm run preview -- --host 127.0.0.1 --port 4323
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs PREVIEW_URL=http://127.0.0.1:4323 node scripts/verify-sakura-motion.mjs
```

浏览器脚本检查实际 Canvas 的数量、尺寸、渐显、风起时位置连续、重复输入及帧率；并覆盖正文像素清空、隐藏控件时停帧、快速导航、实际 BFCache/滚动恢复、暂停/减少动态效果、海滨隔离、手机目录、存储禁用、无 JavaScript 与省流量模式。截图与结果默认保存到 `/tmp/sakura-soft-evidence/`。大纲与海滨沿用现有回归脚本。

验证使用 Chromium 与触屏模拟，不能替代实体手机测量。无 JavaScript 时正文及链接仍可使用，装饰控件保持隐藏。
