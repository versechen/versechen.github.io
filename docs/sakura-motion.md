# 樱花动效与原生页面换场

保持原版首页的居中布局、粉紫渐变、标题、打字文案、星形装饰和三个入口。不加入树插画、不改变正文、目录或海滨主题。

## 花瓣与微风

- 桌面池上限 24，触屏/手机 9，省流量 4；桌面 23–40px、手机 20–32px，前后景有明确尺寸与速度差
- 每瓣独立的弧线摆动、转动与部分翻面；最薄仍保留 62% 宽度，避免变成闪烁碎点
- “风起”沿 5.8 秒正弦平方曲线渐起渐止，位置连续，不增加花瓣，不重排或瞬移；重复点击不叠加
- 常态落速 19–39px/s，叠加分层轻摆与环境风；鼠标只提供经过平滑的有限风力
- 花瓣分批淡入，中心标题、按钮、正文与目录安全区留空

## 花瓣抖落换场与链接行为

普通站内页面链接触发独立的落花层：桌面12片、手机7片、省流量5片，花瓣从上缘三组错落位置先轻抖，再按各自延时释放，随重力加速下落并翻转。32–54px桌面花瓣（手机27–40px）保留清晰单瓣形状，没有树插画、横扫或密集碎点。整个动作约1.25秒，旧页保留320ms让释放动作可见，再调用浏览器原生导航；新页继续同一组落花，配合720ms内容展开。主内容容器不做位移，避免影响固定目录。

日常花瓣与短落花层以同一标签页的 sessionStorage 状态衔接坐标、相位、落下年龄和风速；离开文档时再次保存最新帧，慢加载不会倒退到点击时的画面。状态只对匹配目的地有效，2.5 秒后过期，取出后立即移除。存储禁用时退回新页自然入场。没有客户端路由、没有额外 history 记录，也不使用跨文档 ViewTransition。

- 外链、下载、修饰键、新标签、原页锚点和工作台/文档路由保留浏览器默认行为
- 快速改点目的地以最后一次普通链接为准；旧定时器通过代次验证失效
- Escape、前进后退、隐藏页面、暂停和主题切换会清理待执行离场
- 导航未完成时有有限清理回退，页面不会一直停在淡出状态
- BFCache 恢复不重播入场，保留浏览器自身的焦点与滚动恢复

## 阅读、无障碍与性能

独立暂停沿用 `sakura-effects` 偏好，存储被禁用时仍支持当前页暂停。系统减少动态效果时不绘制花瓣、不延迟导航、无换场动画。窄桌面文章隐藏控件时停止持续背景并清空其 Canvas；宽桌面只在安全边缘绘制，并保留可操作的暂停控件。手机离开首屏或进入正文停止持续绘制。用户主动切页触发的短落花层独立完成后清空并停止，不因为正文保护在中途消失。暂停、减少动态效果和页面隐藏仍同时取消这两层。

后台页面停帧；桌面最多 30fps，手机/省流量最多 24fps；DPR 桌面最多 1.5、手机最多 1.25，总后备像素不超过约 300 万。固定花瓣池与预绘制图块，没有新依赖或外部素材。海滨、记录工作台、编辑器、项目文档不启用本动效。无 JavaScript 时内容与链接可用，装饰控件保持隐藏。

## 验证方式

```sh
npm run verify
npm run preview -- --host 127.0.0.1 --port 4323
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs PREVIEW_URL=http://127.0.0.1:4323 node scripts/verify-sakura-motion.mjs
```

导航单测覆盖资格判断、最终目的地、原生链接语义、Escape、暂停/主题/隐藏中断、BFCache、DOM加载前点击与定时器失效。实际渲染函数的状态测试覆盖重力加速、有限生命周期、连续背景/短转场分离、重复点击不增发、跨文档状态消费和慢加载不倒退；这些模拟测试不替代浏览器观感验证。浏览器脚本采样连续花瓣帧，并检查阅读区像素、暂停、主题隔离、实际前进后退、移动端目录和低动态设置。截图和帧数据默认输出到 `/tmp/sakura-flow-evidence/`。

浏览器脚本需在允许启动 Chromium 的环境运行；单测和构建不能代替真实动画观感验收。触屏模拟也不能代替实体手机验证。
