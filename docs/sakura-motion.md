# 樱花风散与临时落瓣

樱花主题使用一个 Canvas 和一套粉白花瓣：平时少量飘动；切页时一阵风从页面左缘吹过，像吹散一棵看不见的樱花树，花瓣成簇脱离、在页面上散开，再缓缓落下并逐片渐隐，最后恢复平时的数量。原首页布局、海滨主题、文章和目录不变。

## 一段完整的风散

- 桌面常驻池14片，切页临时增加最多28片；手机6＋12，省流量4＋6。实际可见数量还受屏幕边界与阅读保护影响
- 常驻与临时花瓣绘制尺寸都是8–18px；浅白、樱粉渐变。翻转保留至少55%厚度，避免变成细碎亮点
- 点击后约0.22秒，原有花瓣先共同向风向轻偏约24px、略抬6px并倾斜约10°，随后平缓松开；这是同一风相位上的短小摆动，不是加快整屏横扫或增加粒子数量
- 临时花瓣按簇生成（桌面每簇4片，手机/省流量每簇3片），簇心位于页面左缘、上部约12%–42%高度，象征树冠。各簇间隔约0.07秒先后被风带走，约0.5秒内全部离开
- 每片花瓣带着被风抛出的初速度（约0.6–1.3倍屏宽/秒，上下有起伏），同簇花瓣速度各不相同，飞行中自然拉开；空气阻力让初速度按每秒约1.5的系数衰减，之后交还给日常风场继续翻飞、下落。被吹得越快翻转越快
- 每片新增花瓣约3–3.9秒寿命，有独立的淡入、停留与渐隐（寿命过四成后开始淡出），不在统一时间突然删除；整段约4.5秒结束，过期后从临时池移除，下一次入场替换临时池而不累加
- 独立 SVG 转场层不再绘制，避免两层叠加造成密度过高、动作互相掩盖
- 普通站内跨页链接在旧页立即起风，最多保留340ms让花瓣先出现，再由浏览器原生加载新文档。连续改点目的地不重置这段时间；已在加载时更新目标会立即交给浏览器。外链、修饰键、下载、其他target与锚点保持原生行为；同页顶部导航只回到页首，不刷新或重播。没有客户端路由、DOM替换或额外history记录
- Canvas 完成后通知入场状态清理，4500ms兜底不阻塞导航。暂停或系统减少动态效果优先，可立即终止整段动效

旧页将花瓣坐标、抛出速度、相位、风速、剩余寿命和同一episode标识保存在短时sessionStorage中；真正pagehide时再保存最后可见状态，目标页只消费与自身URL匹配的记录并续接，避免慢加载倒带或重播。记录10秒过期，存储不可用/脚本未就绪时链接立即回退到原生导航。Escape及同页取消会停止尚在加载的目标，并清除临时状态。仅在接续回首页时跳过原本从全透明开始的欢迎标题动画，避免风已经接续、标题却重新消失；首次直接打开首页仍保留原入场。

右下角「风起」继续驱动同一画布；日常周期微风与鼠标轻风保留。同视口历史恢复不会重新散布常驻花瓣，新一次入场的临时池有固定上限。

## 阅读、偏好与性能

正文与目录安全区域不绘制花瓣。窄文章隐藏控件时，同时停帧并清空全部花瓣；手机离开首屏或进入正文停止画布。回到有空间的区域时按保存的偏好恢复。临时花瓣经过短页标题后可继续渐隐，不会仅因跨过标题边界被突然切掉；接近受保护的正文或手机首屏边界时提前淡去。

暂停偏好沿用 sakura-effects，存储不可用时仍可控制当前页。减少动态效果、海滨主题、工作台、编辑器、项目文档不启用本动效。页面隐藏时停帧并取消临时花瓣。

仍使用预绘制花瓣图块和一个有界动画循环。桌面最多60fps，手机/省流量最多30fps；DPR上限1.5/1.25，总位图上限约300万像素。没有新运行依赖、树插画或大粒子遮罩。

## 验证

```sh
npm run verify
npm run preview -- --host 127.0.0.1 --port 4323
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs PREVIEW_URL=http://127.0.0.1:4323 node scripts/verify-sakura-motion.mjs
```

渲染函数的生命周期测试验证基线→临时增量→透明度降低→恢复基线，以及重复输入、暂停、减少动态效果、阅读保护与省流量。浏览器脚本采样实际 Canvas 的绘制数量与透明度，保存 breeze-lifecycle-timeline.json，并检查导航、历史、正文、开关、手机和海滨隔离。

Canvas 的 data-sakura-base-pool、data-sakura-base-count、data-sakura-burst-count、data-sakura-burst-state 只用于可重复地观察渲染状态；这些计数不代替连续画面的观感检查。模拟测试与桌面浏览器检查均不能当作实体手机或个人视觉舒适度保证。
