# 树下的微风

首页以一棵疏朗的樱花树为主体，配以「樱花短暂，技术长久」。暖纸色背景、宋体标题和细线按钮留出大面积空白；深色使用低饱和的夜樱配色。树干、左右枝冠及花朵为分层 SVG，19 朵清楚可辨的花分布在枝端，不使用圆点纹理、密集花簇或闪烁装饰。

## 动效与控制

- 平时只轻摇枝条，三个层次的周期分别为 13、16、17 秒，旋转幅度均小于半度。没有自动落樱。
- 点击「风起」时，桌面三片、触屏或窄屏两片花瓣从固定枝端出发，沿 7.2–8.1 秒的轨迹缓缓飘离、淡去。单阵风约 9–10 秒结束；过程不叠加，始终复用三个 SVG 节点。
- 暂停会冻结枝条并收起飘落的花瓣；`sakura-effects` 偏好沿用并持久化。系统减少动态效果时保留静态树，停用全部樱花动画。存储被禁用时仍能控制当前页。
- 画面离开视口、页面隐藏或离开页面时停止动效，取消正在进行的风；BFCache 返回恢复当前偏好，不自动再次落花或重复创建动画。
- 文章及其他内页不挂载樱花树、控制条或粒子层，正文保持安静。海滨主题保留原有画面与交互。

## 页面切换

页面只做 850ms 的轻淡入（不透明度 0.88 → 1），没有横扫、遮罩、位移、缩放或粒子覆盖。保留 Astro 多页导航，不拦截点击，不等待动画再跳转，不替换 DOM，也不修改 history 或滚动恢复。前进与后退采用相同的淡入；动画结束或 1200ms 兜底清理状态，暂停和减少动态效果均会跳过淡入。

## 实现与性能

`SakuraTree.astro` 提供矢量插画，`SakuraEffects.astro` 和 `sakura-effects.ts` 仅在首页加载。没有全屏 Canvas、粒子池、每帧 JavaScript 绘制循环、新依赖或外部图片/字体。短暂落花通过浏览器 Web Animations 执行，常态只有三个缓慢的 SVG 变换。旧花瓣横扫 SVG 已移除。

```sh
npm run test:sakura
npm run test:toc
npm run test:covers
npm run check
npm run build
npm run preview -- --host 127.0.0.1 --port 4323
PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs PREVIEW_URL=http://127.0.0.1:4323 node scripts/verify-sakura-motion.mjs
```

浏览器回归检查真实像素与轻摇、少量花瓣的起点/持续时间/结束、重复风起不叠加、暂停及减少动态效果、后台/视口外停止、快速导航、实际 BFCache/滚动恢复、安静文章、海滨隔离、390/320px 手机布局与目录、520–900px 断点及平板布局、禁用存储和无 JavaScript。截图与结果默认写入 `/tmp/sakura-tree-evidence/`。目录与海滨沿用各自的现有回归脚本。

验证环境使用 Chromium 与触屏模拟，未替代实体手机测量。没有 JavaScript 时树、诗句及导航仍显示为静态页面。网络加载时间仍由原生多页导航决定。
