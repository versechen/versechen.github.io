# 文章左侧整片留白感知

这版覆盖之前的细线/固定坐标入口：桌面没有竖线、按钮或文字提示。`document.pointermove` 按 `.article-main.getBoundingClientRect()` 判断鼠标是否在文章左侧，横向为0至阅读容器left，纵向为当前可见文章范围与导航栏以下视口的交集。排除header/footer；指针移出文档或窗口失焦也退出感知。scroll/resize会根据保存的鼠标位置重新计算。

进入约100ms后显示，返回正文或离开阅读区域后180ms延迟+160ms淡出；无需额外滚动。面板内部及贴近正文的16px间隙保持连续感知。没有透明覆盖层或桥接DOM来截获点击。面板宽236px，阅读列宽860px且居中；原有16px间隙保持。空间不足采用既有紧凑覆盖，不挤正文。

固定/取消固定沿用原逻辑；固定时不因移出隐藏。键盘和读屏仍可访问视觉隐藏的触发按钮，只有键盘焦点到达时才显示焦点入口。触屏保留无字列表图标，打开/关闭/固定正常。

验收路由：`/blog/using-mdx/`、`/blog/markdown-style-guide/`；2048/1440两宽度×两主题×浅深色共16组，各在实际可见阅读区域的上、中、下三处不同x/y坐标测试，精确值见geometry.json。所有坐标均远离旧固定细线，不依赖固定y位置。验证回正文关闭、面板保持、连续间隙、移出页面、pin/unpin、键盘Escape、resize及390触屏，检查居中、16px间隙、无横滚及隐藏不截获点击。另测试首屏/页头/页脚排除、鼠标不动滚动进入阅读区、目录锚点点击后回正文隐藏。

结果：上述16组及补充交互验证全部通过；`npm run check` 0错误/0警告/4既有提示，`npm run build` 32页通过。当前范围内无内容、字体、图片或鉴权变更。
