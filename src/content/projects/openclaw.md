# OpenClaw — Personal AI Assistant

**OpenClaw** 是一个运行在你自己设备上的个人 AI 助手。它通过你已经在用的渠道回答你（WhatsApp、Telegram、Slack、Discord、Google Chat、Signal、iMessage、Microsoft Teams、WebChat），并支持 BlueBubbles、Matrix、Zalo 等扩展渠道。

Gateway 只是控制平面——产品本身就是助手。

如果你想要一个感觉本地、快速、始终在线的单用户个人助手，这就是它。

## 快速上手

推荐使用终端向导完成首次配置：

```bash
openclaw onboard
```

向导会逐步引导你设置 gateway、workspace、渠道和 skills。CLI 向导是推荐路径，支持 **macOS、Linux，以及 Windows（WSL2）**。

也可配合 npm、pnpm 或 bun 安装。

## 核心能力

- **多渠道接入**：把助手接到日常聊天工具，而不是另开一个 App
- **本地优先**：数据与控制权留在你自己的设备上
- **可扩展**：插件与渠道架构便于按需扩展
- **语音与画布**：在支持的平台上可说、可听，并渲染可控制的实时 Canvas
