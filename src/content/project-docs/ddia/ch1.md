# 第一章：可靠性、可扩展性、可维护性

## 可靠性

系统在故障面前仍能正确工作。故障不可避免——硬件损坏、软件 bug、人为失误——可靠系统设计假设它们会发生，并尽量在故障时继续提供服务。

## 可扩展性

描述系统在负载增长时保持性能的能力。关键是先定义负载参数与性能指标，再讨论应对策略（垂直扩展、分区、缓存等），而不是空谈「高并发」。

## 可维护性

长期演进的成本。好的可操作性、简单性与可演化性，决定团队能否在几年后仍敢于改动系统。
