MDX 在 Markdown 基础上增加了组件与表达式能力，适合需要复用设计组件、数据卡片或交互岛的文章。

## 什么时候使用 MDX

- 普通技术文章优先使用 `.md`，内容更容易迁移。
- 需要嵌入 Astro 组件时使用 `.mdx`。
- 真正需要浏览器交互时，再为框架组件添加 `client:*` 指令。

> [!IMPORTANT]
> Astro 组件默认在构建时渲染，不会自动向浏览器发送 JavaScript。这能保持文章页面快速、稳定。

## 嵌入组件

下面的链接复用了项目已有的 `HeaderLink.astro` 组件：

<HeaderLink href="/blog">
  返回博客列表
</HeaderLink>

对应的 MDX 写法：

```mdx
import HeaderLink from '../../components/HeaderLink.astro';

<HeaderLink href="/blog">
  返回博客列表
</HeaderLink>
```

更多细节可参考 [Astro MDX 官方文档](https://docs.astro.build/en/guides/integrations-guide/mdx/)。
